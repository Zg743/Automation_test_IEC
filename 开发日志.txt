八、kf_iec_datetime.py（新建）

- last_day_of_month(date_str)：传入 YY-MM-DD，返回当月最后一天 YYMMDD。示例：('26-09-01') -> '260930'

    if not status:

二十七、新增 kf_popup.py 弹窗工具
- kf_alert(title, message)  : 后台线程弹非模态警告框，不阻塞脚本运行，点确定/关闭后消失
- kf_prompt(title, message) : 主线程阻塞弹提示框，点确定后脚本才继续

  弹出前也会 +1，所以任何一种新弹窗都会自动踢掉上一个 kf_alert

二十九、新增 kf_07_heartbeat.py 心跳模块（水表定时休眠场景）
- 背景: 水表会定时休眠，不想手动唤醒，需定时发心跳帧维持可通信状态
- Heartbeat 类: start() 启动后台守护线程按固定间隔发帧，stop() 停止；
  默认帧 68 AA*6 68 13 00 DF 16(645/97 读通讯地址)，interval/frame 可定制
- 串口字节宽度(7E1/8E1/8N1)由调用方自行切换管理，本模块只发原始字节
- 串口竞争: IEC62056ModeE 新增 io_lock(threading.Lock)，
  _send/_read_frame 均持 io_lock；Heartbeat 也持同一把锁写入，
  从而实现共享串口访问串行、帧不交错
- 已用假串口实测: 0.1s 间隔 0.35s 内正确发送 3 次、帧内容一致

三十、新增 sts_token_recharge.py STS 充值 Token 生成/解码模块
- 实现 IEC 62055-41:2018 (EA07 / STA) 标准的 STS token 算法
- generate_token(key_hex, tid, subclass, amount): 传入密钥/TID/类型/充值量，
  返回充值 Token 字符串。subclass: 0=电用量 1=水用量 2=气用量 3=时间，
  4=电金额 5=水金额 6=气金额 7=时间金额
- decode_token(token_64, key_hex): 传入 Token 和密钥，返回字典
  (class/subclass/rnd/tid/amount_field/crc_ok/units/amount)
- 内部含 sta_encrypt/sta_decrypt(16轮SPN网络)/amount_to_field/field_to_amount
  /crc16_sts 等，算法已通过 STS Simulator 对照验证（水表 sub=1 amount=1m3
  -> 63525115892327740484，电表 sub=0 amount=10kWh -> 35500312443047940328）
- 也可命令行直接使用: python sts_token_recharge.py <key_hex> <tid> <subclass> <amount>
